这个文件夹包含了部署到 Vercel 所需的所有必要文件。

- ✅ `src/` - 所有源代码
- ✅ `package.json` - 项目依赖配置
- ✅ `next.config.js` - Next.js 配置

- ✅ `postcss.config.js` - CSS 处理配置

### 🚀 部署步骤：

#### 方法1：上传到 GitHub
1. 访问：https://github.com/susu9918/susu
2. 删除所有旧文件
3. 上传这个文件夹内的所有文件
4. 提交信息：`Deploy susu&hz mood share app`

#### 方法2：直接上传到 Vercel
1. 访问：https://vercel.com
2. 注册/登录账户
3. 点击 "New Project"
4. 选择 "Upload" 或 "Browse"
5. 上传这个文件夹
